# Введение

:::info[Оригинал]
[docs.nestjs.com — Introduction](https://docs.nestjs.com/) · NestJS 12.1 · перевод от 01.10.2026
:::

Nest (NestJS) — фреймворк для создания эффективных и масштабируемых серверных приложений на [Node.js](https://nodejs.org/). Он использует прогрессивный JavaScript, написан на [TypeScript](https://www.typescriptlang.org/) и полностью его поддерживает (при этом позволяет писать и на чистом JavaScript), а также сочетает в себе элементы ООП (объектно-ориентированного программирования), ФП (функционального программирования) и ФРП (функционального реактивного программирования).

Под капотом Nest использует надёжные HTTP-фреймворки — [Express](https://expressjs.com/) (по умолчанию), а при желании его можно настроить на работу с [Fastify](https://github.com/fastify/fastify).

Nest добавляет уровень абстракции поверх этих популярных Node.js-фреймворков (Express и Fastify), но при этом даёт разработчику прямой доступ к их API. Благодаря этому можно свободно пользоваться огромным количеством сторонних модулей, доступных для нижележащей платформы.

## Философия {/* #philosophy */}

В последние годы благодаря Node.js JavaScript стал «лингва франка» веба — и для фронтенда, и для бэкенда. Это дало толчок таким проектам, как [Angular](https://angular.dev/), [React](https://github.com/facebook/react) и [Vue](https://github.com/vuejs/core), которые повышают продуктивность разработчиков и позволяют создавать быстрые, тестируемые и расширяемые фронтенд-приложения. Однако, хотя для Node.js (и серверного JavaScript) существует множество отличных библиотек, утилит и инструментов, ни один из них по-настоящему не решает главную проблему — проблему **архитектуры**.

Nest предоставляет готовую архитектуру приложения, которая позволяет разработчикам и командам создавать хорошо тестируемые, масштабируемые, слабо связанные и легко поддерживаемые приложения. Эта архитектура во многом вдохновлена Angular.

## Установка {/* #installation */}

Чтобы начать, можно либо сгенерировать каркас проекта с помощью Nest CLI{/* TODO-LINK: https://docs.nestjs.com/cli/overview — CLI → Overview */}, либо [склонировать стартовый проект](#alternatives). Оба способа дают одинаковый результат.

Чтобы создать проект через Nest CLI, выполните команды ниже. Они создадут новую директорию проекта и наполнят её основными файлами Nest и вспомогательными модулями — так у проекта появится стандартная базовая структура. Новичкам мы рекомендуем использовать **Nest CLI**, и в главе [«Первые шаги»](./overview/first-steps.md) продолжаем именно с этим подходом.

```bash
$ npm i -g @nestjs/cli
$ nest new project-name
```

## Альтернативы {/* #alternatives */}

Также можно установить стартовый проект на TypeScript с помощью **Git**:

```bash
$ git clone https://github.com/nestjs/typescript-starter.git project
$ cd project
$ npm install
$ npm run start
```

:::tip[Подсказка]
Чтобы склонировать репозиторий без истории Git, используйте [degit](https://github.com/Rich-Harris/degit).
:::

Откройте браузер и перейдите по адресу [`http://localhost:3000/`](http://localhost:3000/).

Чтобы установить стартовый проект на JavaScript, используйте `javascript-starter.git` в командах выше.

Можно также начать новый проект с нуля, самостоятельно установив основные и вспомогательные пакеты. В этом случае шаблонные файлы проекта придётся настроить вручную. Как минимум понадобятся следующие зависимости: `@nestjs/core`, `@nestjs/common`, `rxjs` и `reflect-metadata`. Пошаговое руководство по созданию полноценного проекта таким способом — в статье [5 steps to create a bare minimum NestJS app from scratch](https://dev.to/micalevisk/5-steps-to-create-a-bare-minimum-nestjs-app-from-scratch-5c3b) (на английском).
