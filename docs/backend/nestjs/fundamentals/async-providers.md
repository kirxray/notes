# Асинхронные провайдеры

:::info[Оригинал]
[docs.nestjs.com — Asynchronous providers](https://docs.nestjs.com/fundamentals/async-providers) · NestJS 12.1 · перевод от 04.10.2026
:::

Иногда запуск приложения нужно отложить, пока не завершатся одна или несколько **асинхронных задач**. Например, вы можете не хотеть принимать запросы, пока не установлено соединение с базой данных. Асинхронные провайдеры позволяют это сделать.

Чтобы создать такой провайдер, используйте `async/await` вместе с синтаксисом `useFactory`. Фабрика возвращает `Promise`, а фабричная функция может ожидать (`await`) асинхронные задачи. Nest дожидается разрешения промиса, прежде чем создавать экземпляр любого класса, который зависит от такого провайдера (внедряет его).

```ts
{
  provide: 'ASYNC_CONNECTION',
  useFactory: async () => {
    const connection = await createConnection(options);
    return connection;
  },
}
```

:::tip[Подсказка]
Подробнее о синтаксисе пользовательских провайдеров — в главе [«Пользовательские провайдеры»](./custom-providers.md).
:::

## Внедрение {/* #injection */}

Асинхронные провайдеры внедряются в другие компоненты по своим токенам, как и любой другой провайдер. В примере выше нужно использовать `@Inject('ASYNC_CONNECTION')`.
