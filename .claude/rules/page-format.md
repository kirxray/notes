# Оформление страницы

- Frontmatter: `title` (по-русски) и `sidebar_position`.
- Сразу после `# Заголовка` — блок с оригиналом, версией и датой перевода:

  ```md
  :::info[Оригинал]
  [docs.nestjs.com — Introduction](https://docs.nestjs.com/) · NestJS 12.1 · перевод от 01.10.2026
  :::
  ```

- Заголовки разделов — с явным английским id из оригинала, чтобы якоря совпадали: `## Установка {/* #installation */}` (синтаксис Docusaurus 3.10+; старый `{#id}` при `future.v4` ломает сборку).
- Подсказки оригинала (`> info **Hint**`, `> warning **Warning**`, ...) → admonitions: `:::tip[Подсказка]`, `:::warning[Внимание]`, `:::info[Примечание]`.
- Свои комментарии, которых нет в оригинале, — только в `:::note[Примечание]`.
- Код и команды не переводим; комментарии внутри кода переводим.
- Термины без устоявшегося перевода оставляем на английском, при первом упоминании поясняем.

## Разметка исходников docs.nestjs.com

Исходники берём в сыром виде: `https://raw.githubusercontent.com/nestjs/docs.nestjs.com/master/content/<путь>.md`.
Имя исходника не всегда совпадает с URL (`/providers` → `content/components.md`). Если raw отдаёт 404 — искать по дереву репозитория: `curl -s "https://api.github.com/repos/nestjs/docs.nestjs.com/git/trees/master?recursive=1" | grep content/`. Имя нашего файла всё равно берём из URL (`providers.md`).

- `@@filename(main)` → заголовок блока кода: ` ```ts title="main.ts" `.
- `@@switch` и всё после него до конца блока (JS-вариант) — удаляем, оставляем только TS. Вкладки `<Tabs>` TS/JS не делаем.
- `@@filename()` без имени → блок без `title`.
- `<div class="file-tree">` → блок ` ```text ` с деревом (`├──`, `└──`).
- HTML-таблицы (`<table>`) → markdown-таблицы; сноски вида `<span class="table-code-asterisk">*</span>` → `\*` в ячейке и `<sup>\*</sup>` под таблицей.
- Таблицы без шапки → добавляем осмысленную шапку (`Файл | Описание`, `Пакет | Описание`).
- `{{ '{' }}` / `{{ '}' }}` (экранирование Angular) → обычные `{` / `}`.
- Картинки `/assets/<Name>.png` → скачать с `https://docs.nestjs.com/assets/<Name>.png` в `static/img/nestjs/<kebab-name>.png`, вставлять как `![Описание](/img/nestjs/<kebab-name>.png#themed)` — `#themed` инвертирует светлую схему в тёмной теме (CSS в `src/css/custom.css`).
- Блоки ` ```plaintext ` → ` ```text `.
- `<app-banner-*>` и прочие рекламные/служебные Angular-компоненты — удаляем.

## Что не переносим

Цель — только то, что нужно для работы на TypeScript. Не тащим в проект:

- JavaScript-варианты кода (`@@switch`) и блоки кода, у которых нет TS-аналога (примеры с `@Bind()`, `@Dependencies()` и т. п.).
- Рекламные и служебные компоненты оригинала (`<app-banner-*>`, курсы, Devtools и т. п.).
- Картинки, которые не несут смысла (логотипы, баннеры); схемы — переносим.

Текст оригинала при этом переводим полностью, даже если он упоминает JavaScript (например, «стартовый проект на JavaScript»). Если фраза описывает то, чего на нашем сайте нет (переключатель языка), — переводим как есть и добавляем `:::note[Примечание]`.
